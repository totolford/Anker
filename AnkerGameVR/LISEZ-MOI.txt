ANKERGAME VR - Prototype Windows

CONTENU
- AnkerGameVR.py : lanceur graphique Windows.
- games.json : créé automatiquement pour enregistrer la bibliothèque.

DEMARRAGE
1. Installe Python 3 depuis https://www.python.org/downloads/windows/
   Pendant l'installation, coche "Add Python to PATH".
2. Décompresse ce dossier.
3. Double-clique sur AnkerGameVR.py (ou lance `python AnkerGameVR.py`).
4. Clique sur "+ Ajouter un jeu" et choisis le fichier .exe d'un jeu déjà installé.
5. Sélectionne le jeu puis clique sur "Lancer le jeu sélectionné".

IMPORTANT
Ceci est un prototype de lanceur : il organise et démarre les jeux Windows.
Il ne transforme pas un jeu 2D/classique en jeu VR. Pour une vraie VR, le jeu doit
avoir un mode VR natif ou un mod compatible, et le casque/runtime doit être pris
en charge par le PC. Le Meta Quest 1 et les versions actuelles des logiciels Meta
peuvent présenter des limites de compatibilité. FNAF: Help Wanted doit être
installé légalement et sa version PC doit être compatible avec la configuration.
